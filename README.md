# PixelGallery --- Image Gallery

A responsive image gallery website built with **HTML, CSS, and
JavaScript**. Browse images of cars, animals, and cities, search for
images, save favorites, upload your own pictures, and view images in a
lightbox.

## Features

-   Responsive layout for desktop, tablet, and mobile
-   Image categories: Cars, Animals, and Cities
-   Search images by title, category, or description
-   Lightbox viewer with next and previous navigation
-   Add and remove favorite images
-   Upload custom images with a title, category, and description
-   Delete uploaded images
-   Image filters: Original, Black & White, Sepia, Vivid, and Blur
-   Dark and light themes
-   Saves uploaded images, favorites, and theme preference in browser
    storage
-   Placeholder graphics if a sample image cannot load

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript
-   Unsplash images for sample photos

## How to Run

1.  Download or clone this repository.
2.  Open the `PixelGallery` folder in Visual Studio Code.
3.  Make sure `index.html`, `style.css`, and `script.js` are in the same
    folder.
4.  Open `index.html` in your browser.

For a convenient development workflow, you can install the **Live
Server** extension in Visual Studio Code, right-click `index.html`, and
choose **Open with Live Server**.

No build tools or package installation are required.

## How to Use

1.  Choose a category to browse images.
2.  Use the search field to find images by title, category, or
    description.
3.  Select an image to open the large image viewer.
4.  Use the next and previous buttons, or the keyboard arrow keys, to
    navigate.
5.  Select the heart button to add or remove an image from Favorites.
6.  Use the filter buttons to apply an image effect.
7.  Select **Upload Image** to add your own image, title, category, and
    optional description.
8.  Switch between dark and light themes using the theme button.
